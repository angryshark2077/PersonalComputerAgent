Debug without speculative rewrites.

1. Reproduce and capture exact failure.
2. Classify: contract, permission, process, DB, sync, provider, update, UI.
3. Trace correlation IDs and state transitions.
4. Identify first incorrect state, not last visible symptom.
5. Add a failing test.
6. Implement the smallest fix.
7. Run regression and failure-path tests.
8. Report evidence.
